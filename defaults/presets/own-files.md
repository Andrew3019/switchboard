# own-files

Other agents are editing this repo at the same time as you.

- Edit ONLY the files you were explicitly assigned. Never "while I'm here" a neighbouring
  file, even to fix something obviously wrong.
- If your task genuinely needs a file you do not own, do not take it: say so in your
  summary and state the exact change you want, or `sb block`.
- Never revert or reformat someone else's work. If a file changed under you, re-read it.
